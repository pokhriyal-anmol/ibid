# AGENTS.md

Guide for AI coding agents working in this repo. Humans: start with [README.md](README.md).

## What this is

Ibid returns verbatim text and exact citations for the IPC and the BNS, using code only. The vocabulary is in [CONTEXT.md](CONTEXT.md). Use those terms (Act, Provision, Citation, Cross-reference, Concordance, Evidence packet, Gold set, Baseline) and not their listed synonyms.

## Commands

The source PDFs are gitignored. In a git worktree they are missing, so point the env vars at the root checkout by absolute path.

```bash
uv sync
uv run ibid setup --fetch bns                          # then --fetch ipc --url <link>; plain `ibid setup` checks tools, PDFs, counts
export IBID_BNS_PDF=<root>/data/raw/bns-prs.pdf IBID_IPC_PDF=<root>/data/raw/ipc-wipo.pdf

uv run python -m unittest discover -s tests                 # all tests, about 30 s
uv run ibid eval --gold gold/v2.json --concordance concordance/v2.json --out results/run.json
uv run ibid eval --mode draft --gold <file>                 # unpinned gold, experiments only
uv run ibid conform ...                                     # apply text conventions to drafted gold
uv run ibid freeze ...                                      # apply a review sheet, write pinned v1
```

Tests are `unittest`. There is no pytest. Needs `pdftotext`, `pdftohtml`, `pdfseparate`, `pdfunite` (poppler).

## Rules

1. **No model in retrieval.** Retrieval takes the raw query only ([ADR 0001](docs/adr/0001-retrieval-independent-of-the-model.md)). Do not add a model call, a query rewrite or an embedding step to the baseline path.
2. **Frozen gold is never edited in place.** Make a new version file and a new pin. `gold/v2.json` must match `gold/v2.sha256`, and `concordance/v2.json` its pin.
3. **Do not tune to the gold set.** Fixing a parser bug is fine. Editing an answer so the system passes is not. Drop a defective item by name with a reason, as `ibid conform --drop` does.
4. **Never commit the source PDFs** or anything under `data/raw/`. CI fails if a PDF is tracked.
5. **Test through one seam**: the `ibid eval` command. Test behaviour, not internals.
6. **A check you have not seen fail is not a check.** Run each new test once against known-bad input, and assert on the loaded value after any mutation (clear `__pycache__` first).
7. **Python 3.11+, standard library only** ([ADR 0002](docs/adr/0002-python-and-sqlite.md)). Do not add a dependency without asking.
8. Commits follow Conventional Commits (`feat`, `fix`, `refactor`, `test`, `docs`, `chore`).

## Conventions the data follows

- A section's text includes its illustrations. A subsection's text includes its attached explanations. Children are also provisions of their own.
- A sub-provision's text starts at its own label (`(1)`), with no section-number prefix.
- Amendment marks (`[ ]`, `***`) and footnote numerals are not part of the text.
- A provision does not list itself as a cross-reference target.
- Keyword answers are provision-level sets, scored without regard to rank order.

## Gotchas

- `ibid eval` defaults to scored mode and refuses an unpinned gold file. Use `--mode draft` for drafts.
- Results record `parser_version`. Bump `PARSER_VERSION` in `parse.py` whenever parsing output changes.
- `tests/fixtures/bns-parse-fingerprint.json` pins hashes of the whole BNS parse and its cross-references (no text). CI fails if parsing or cross-reference output changes. When the change is intended, bump `PARSER_VERSION`, then run `uv run python tests/test_bns_fingerprint.py --write` and commit the new file.
- Do not read the Act PDFs into context. To check one page use `pdftotext -f N -l N data/raw/<file>.pdf -`. `ibid conform` reads per-page text from `data/raw/pages/{bns,ipc}/NNN.txt`, which is not generated by any command yet: create it with `pdftotext -f N -l N` per page (1-based, zero-padded to three digits).
