# Q-003: How to read decision 5 for links v1 (kept or negative)

Status: pending
Slug: slice-7
Raised by: wf-tickets (ticket 7 planning) and wf-build, ticket 7 (links v1 decision report)
Blocking: no
Reversible: yes

## Question

Spec decision 5 says `links v1` is kept as an opt-in output only if "per-charge recall rises on both multi-charge sets" and ILSI test micro-F1 does not fall. It does not say at what level recall is compared. ILSI micro-F1 rose for both output rules (9.37 to 11.37 top-k, 9.64 to 11.81 threshold), so only the recall reading decides the verdict. Which reading do you want?

The two workflows took different defaults. Ticket planning assumed the strict reading. The build used the pooled reading and reported KEPT. `CONTEXT.md` says a layer must beat the Baseline "on the same set and the same Act", which points to a per set and Act reading. Under that reading the verdict is NEGATIVE, because set v2 BNS ties on both output rules (8 to 8, 5 to 5).

## Why only you

The rule was fixed before any score so that nobody could choose its reading after seeing results, and the build chose one after the scores existed.

## Options

1. Pooled per set, over both Acts and both output rules (the build's default). Set v1 goes 17 to 21 charges found, set v2 22 to 30. Verdict KEPT as opt-in; MCP wiring can be considered in a later slice.
2. Per set and Act, as `CONTEXT.md` defines the Baseline comparison. Set v2 BNS gains nothing. Verdict NEGATIVE; the links module stays a documented dead end and nothing is wired into the MCP server.
3. Strict per cell (set x Act x output rule, 8 cells). 2 of 8 cells gain nothing. Verdict NEGATIVE, same effect as option 2.

## Default taken

Option 1. `.scratch/slice-7/report.md` and the Outcome paragraph of `docs/adr/0007-definition-punishment-links-from-headings.md` say KEPT under the pooled reading and state that the strict and per set-and-Act readings would give NEGATIVE. Nothing is wired into `src/ibid/mcp.py`, so either answer is still open.

## If you answer differently

Options 2 or 3: change the verdict line in `.scratch/slice-7/report.md` (and the rule in `.scratch/slice-7/report.py` that computes it), rewrite the ADR 0007 Outcome paragraph to NEGATIVE, and update any `CONTEXT.md` or spec text that calls links v1 an opt-in output. No scores are rerun; all figures stay as they are.
