# Q-005: Which label space the ILSI test micro-F1 floor for assoc-nb v3 is scored over

## Question

Spec decision 7 says v3 is kept only if its ILSI test micro-F1 is at least 33.4 (v1's 35.4 minus 2). `ibid assoc eval` scores micro-F1 over the model's own label space. v1's space is the ILSI label vocabulary (100 labels). v3's is the IPC sections with at least 5 training examples in the union (140 labels). A gold label outside a model's space adds no missed charge, so a different space can move the score without finding more charges. Should v3 be compared with the 33.4 floor over its own label space, or over v1's?

The same spec line says "all six comparisons", but it lists five. The only candidate for a sixth is this same figure over v1's label space, so that count is folded into this question.

This now decides the verdict. The single ILSI test run (`results/layers/assoc-nb-v3-test.json`, ledger entry in `results/test-ledger-assoc.json`) recorded both figures: 35.2 over v3's own space (passes) and 33.3 over v1's space (33.317, fails the 33.4 floor). Comparisons 1 to 4 all pass.

## Why only you

D-002 says a decision rule must name its comparison level before any score, the spec does not name this one, and the scores now exist, so picking the reading now is the post-hoc choice only you can make.

## Options

1. v3's own label space, five comparisons (the build's default). Same procedure that produced v1's 35.4. Verdict KEPT as an opt-in layer.
2. v1's label space for both, five comparisons. Like for like on the same charges. Comparison 5 fails (33.3 against 33.4), verdict NEGATIVE; v1 and v2 remain the two options.
3. Both spaces gated, six comparisons (the spec's count). v3 must clear 33.4 on each. The v1-space figure fails, verdict NEGATIVE, same effect as option 2.

## Default taken

Option 1. `.scratch/slice-9/v3-report.md` says KEPT with five comparisons, notes the spec's "six" counts to five, and prints both label-space figures and sizes. ADR 0008 states the five thresholds and records the v1-space figure beside the main one without gating it.

## If you answer differently

No rescoring: both figures came from the one test run. Options 2 or 3 change the verdict rule in `.scratch/slice-9/v3-report.py` and the regenerated `.scratch/slice-9/v3-report.md`, the verdict clause and Outcome of `docs/adr/0008-association-layer-fitted-on-both-kinds-of-text.md`, the assertions in `tests/test_v3_report.py` and `tests/test_adr_0008.py`, and any spec, `CONTEXT.md` or `pr.md` text calling v3 kept. Option 3 also changes the report's comparison count from five to six.
